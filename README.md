# Repo & Funding Analytics

Personal Python/Streamlit project focused on repo trading and funding analytics

### Features
- Sovereign repo portfolio monitoring and P&L analysis
- Repo and money market deposit pricers
- Multi-currency FX swap pricing
- Front Office / Product Control reconciliation

### Technologies
Python · Pandas · Streamlit · Plotly

### Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

**Disclaimer:** All transactions and P&L figures are simulated
